Bundled xterm.js terminal emulator used by the web console SSH terminal view.

* `xterm.js`, `xterm.css` - @xterm/xterm 5.5.0 (MIT, see LICENSE.xterm)
* `addon-fit.js` - @xterm/addon-fit 0.10.0 (MIT, see LICENSE.addon-fit)
* `terminal.html` - NetXMS page connecting the terminal to `/sshterminal/{id}` websocket endpoint

Files are taken unmodified from the npm packages (`lib/xterm.js`, `css/xterm.css`, `lib/addon-fit.js`).
